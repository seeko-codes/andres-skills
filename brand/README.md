# Turn to Life — visual identity

A purposeful path through growing complexity. The GitHub README is a **Read** surface:
help a visitor understand the workflow, start using it, then find the detail they need.

- **World:** evergreen `#142b24`, cream `#f7f4e9`, spring green `#b9e58c`; gold marks the seed.
- **Type:** editorial serif in the wordmark; GitHub's native typography for selectable prose.
- **Hierarchy:** one introduction, one primary installation path, conditional detail in native disclosures.
- **Restraint:** no decorative animation, badge wall, fake metrics, section-number ornaments, or new frontend runtime.
- **Truth:** artwork expresses the idea; it is not a technical diagram or evidence of efficacy.

## Asset

[hero.webp](hero.webp) is the original project artwork, generated with OpenAI image generation
and refined through Impeccable's Read-mode and polish guidance. Its earlier small promotional
text was removed; the name and promise remain selectable in the README. The evergreen field
contains its own contrast in both GitHub themes. Alternative text describes the mark.

One optimized, locally served WebP is retained, not a gallery of variants. Consumers need
no image-generation, font, image-hosting, or animation dependency. The installer copies only
skills, so the brand asset adds no weight to an installed project's method library.

## Method and references

This pass used the already installed **pbakaus/impeccable v4.1.1** skill, scoped to refinement
of an existing identity. It was not copied into the bundle or made a runtime dependency.
Design authority lives here rather than in a second PRODUCT/DESIGN documentation hierarchy.

The initial direction studied [Resend](https://github.com/resend/resend-node)'s focused hero,
[Charm](https://github.com/charmbracelet/bubbletea)'s visual personality, and
[Supabase](https://github.com/supabase/supabase)'s concise promise and hierarchy.
Those are design observations, not endorsements; their artwork was not copied.
